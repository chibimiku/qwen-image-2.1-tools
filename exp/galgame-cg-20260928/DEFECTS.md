# out/ 出图缺陷排查报告

对 `out/` 里 **37 张**出图（bracket 7 + 对照 12 + 正片 12 + 修补 3 + seeds 3）做了逐格排查：
先按"配方分组"拼检查表看全，再对可疑格逐块放大确认，最后跑一遍客观像素扫描。
排查工具：`sheets.py`（分组检查表）、`zoom.py`（局部放大）、`scan_defects.py`（像素扫描）。

**结论先说**：问题集中在**正片**，而且成因不是"模型画不好"，
是**我喂的参考图与样式词在互相打架**，加上**正片只跑了一个 seed 就定稿**。

## 二、成因分析

### 2.1 过曝与"镜子画不出来"：角色立绘的纯白背景被带进了画面

`refs/char.png` 是**纯白背景的立绘**。把它作为 `<image1>` 送进去，
模型不只学到"人物长什么样"，也学到"**画面背景是白的**"。

同时我的样式词又在要**暗底 + 轮廓光 + 高对比**（这是画风参考图的光学特征），
而内容描述里 01/04 恰好是"明亮的室内/海边"——**三方互相冲突**：

```
角色立绘（白底平光） ──┐
样式词（暗底强对比）   ──┼──► 模型折中 → 大块死白
内容描述（明亮场景）   ──┘
```

镜子那张尤其典型：prompt 写了 `tall gilt-framed mirror`，但模型的注意力被
"白底立绘"带走，把左侧直接渲染成死白 —— **镜子这个物体根本没生成**。
我不是没看，是**把死白误当成了镜面高光**，这是人工 review 的漏判。

### 2.2 同一角色出现两次：参考图里的"整个人物"被复用了两次

`<image1>` 提供的是一整张立绘（一个人 + 白底）。当 prompt 描述的构图里
"画面中的人"与"被观察的人"可以分开时（`looks back over her shoulder`、
`seen from a three-quarter angle as she turns`），模型会把参考图里的人
**既当主体又当第二个人**画出来。

证据：同一 prompt 我在修补时加了 `Exactly one girl in the frame, alone`
就修好了 —— **说明缺的是显式的"人数"约束**，而不是模型能力不足。

### 2.3 手部崩坏：prompt 过载，注意力被摊薄

本次 prompt 的结构是：

```
分工声明(50词) + 样式词(60–90词) + 禁止清单(60词) + 角色圣经(90词) + 场景(40词)
```

**手部不在任何一段里**。而 12/11 恰好都要求具体手部动作
（`both hands holding her small shopping bag`、`one hand raised to catch them`）。
C 组（只给画风图）的 prompt 更短，手部反而没崩 —— 侧面印证是**指令密度**问题。

### 2.4 景别不一致：12 段的镜头描述是各写各的

我在写 `SCENES` 时给每一幕单独写了 `wide cinematic composition, full body` /
`upper body` / `medium shot`，但**没有一个统一的景别规则**，
所以同一套 CG 里出现了从"只有头"到"全身+大场景"的跳变。

### 2.5 系统性成因：正片只跑了一个 seed

这是最根本的一条。跨 seed 检查已经证明这个组合有**整张作废级**的失败模式
（seed 20260927 出现两个人）。而**正片 12 幕全部只跑了 seed 42**，
等于每张都只掷了一次骰子。上面 1/2/3 三个高危缺陷，本质上都是
"**掷到坏结果就直接定稿**"。

## 三、按成因给出的修法（按性价比排序）

| 优先级 | 做法 | 针对的缺陷 | 成本 |
|---|---|---|---|
| **1** | **每个场景跑 3 个 seed，人眼挑** | 1/2/3/4 全部 | 3× 出图时间（每张约 42s） |
| **2** | prompt 里**显式写人数**：`Exactly one girl in the frame, alone` | 3（已用修补验证有效） | 0 |
| **3** | **角色立绘先去白底**（抠成透明或换中性灰底）再当 `<image1>` | 1/2（白底污染） | 本地一次处理 |
| **4** | 场景描述里**点名背景要有内容**（列 3–4 个环境元素） | 1/2（已用修补验证有效） | 0 |
| **5** | 12 幕**统一景别规则**（例如全部 `full body, subject off-centre`） | 7 | 0 |
| **6** | prompt 里**单独一句描述手在做什么**，并减少禁止清单长度 | 4/5 | 0 |

> 第 3 条值得特别说明：立绘的白底是**污染源**，不是中性的。
> 报告里 1、2 两个高危缺陷都指向它。抠底后再喂，应该能同时改善过曝与"镜子不生成"。

## 四、这次排查暴露的方法问题

1. **我用缩略图下的判断不够可靠**。01 的"镜子"我第一遍看成高光，
   放大后才确认是死白。**结论性判断必须看原尺寸局部。**
2. **像素扫描解决不了语义缺陷**。`scan_defects.py` 只抓到过曝（1/2），
   对"两个人""糊手""镜子没画"完全无感。它不是人眼的替代品。
3. **"改完就好"要有对照**。01/04/06 的修补版确实好了，
   但那是**我同时改了样式词 + 场景描述**两处 —— 和主实验里 F 组犯的是同一个错：
   **一次动两个变量，就无法归因**。
