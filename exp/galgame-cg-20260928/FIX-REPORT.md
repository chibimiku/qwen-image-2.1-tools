# 出图修复记录：10 张重出 + 逐项验证

对 `out/` 里质检出的缺陷图做了一轮本地修复重出，产物在 `fixed-2/`。

**做法**：不是逐张手写新 prompt，而是**把缺陷类型翻译成固定的修正句**
（见 `prompts_fix.py` 的 `FIXES`），再叠进原有的四段 prompt。这样改一处、
所有相关图一起受益，也便于事后对账"哪句治好了哪个缺陷"。

**判定由 agent 自己看图**，不依赖外部视觉 API（`run_fix.py` 只负责出图）。

## 三、修的过程中踩出来的两个新失败模式（都已解决）

### 3.1 只发场景段 → 模型退回白底立绘

第一版 `run_fix.py` 把 `scene`（角色圣经 + 场景）当整条 prompt 发出去，
**丢掉了分工声明 / 样式词 / 禁止清单三段**。结果 `story-12` 从 0% 纯白变成 **88%**，
画面变成白底立绘、场景全没。

→ 修成发完整四段，并加了两道护栏：`run_fix.py` 发前检查段数 ≥4、
`check_fix_prompts.py` 逐张核对四个必备要素（分工声明/样式词/禁止清单/角色圣经）。

### 3.2 竖版参考图 → 宽画布两侧留白

修完发现 `story-09` 变成**竖幅夹在白色里**（纯白 71%）、`story-03` 泛白 45.9%。
原因是画风参考图是 832×1216 竖构图，模型跟着它的取景走，再贴到 1600×896 上就留白。

→ 加了一句**所有图通用的满幅要求**（`FULL_BLEED`，放在样式词之后）：
"画面横向铺满整个画幅，背景延伸到左右边缘，两侧没有白色空条"。
加上把样式词统一换成 `boost` 之后，10 张全部回到 ≤0.46%。

> 这里有个判断：这两条**不是**某张图的问题，是"竖参考图 + 宽输出"这个组合的通病，
> 所以做成了基础约束而不是逐图补丁。

## 四、还没解决的（如实记录）

**`hands_grip` 只做到一半。** `story-12` 放大后：手指有了结构、袋子有了提手和包体，
但**提手被画成两根细竖条、上方两个金环悬着，手指没真正绕住它**。
`story-03` 同样：手还在袋子后面，只是"看起来像握着"。

我把原来的 "手指与提绳焊成一坨" 改善成了 "手与提手各自有结构但接触关系不成立" ——
**是进步，不是解决**。再往下要试的方向：把提手的几何写死（"提手是一根 U 形皮带，
两端固定在包口"）、或者干脆改成不依赖精细握持的动作（手插兜 / 双手捧包）。

**另外三张没在这一轮里**：`boost-03-street`、`fix-01-boutique`、`seed-*`
也有缺陷（见 `qa/merged.csv`），本轮只修了正片 12 幕里出问题的 10 张 + `fix-04`。

## 六、方法上的结论

1. **把缺陷翻译成固定修正句，比逐张改 prompt 更值。** 8 类缺陷、10 张图，
   只写了 7 条修正句。而且"哪句有用"能直接从对照上看出来（见第二节）。
2. **任何改动都要有客观量兜底。** 过曝/死黑用像素统计一测就知道，
   不需要争论；这一条在 3.1 那次事故里起了决定性作用 ——
   数字直接指出 88% 是坏的，而肉眼看缩略图容易放过。
3. **修 A 会引入 B。** 满幅留白就是修过曝带出来的。所以要**每轮都全量重测**，
   不能只看"改的那一项有没有好"。
4. **判定的独立性很重要。** 三批识图 + 我自己的检查互相发现了对方漏掉的东西
   （识图发现了玛丽珍鞋跟的重影、fix-04 的黑天空；我发现了两处误报）。
