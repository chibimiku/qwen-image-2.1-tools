## 使用规则

- 这些代码**只描述我看见的东西**；分数是判断，代码是依据。任何一行都能按
  `jobs/<id>/<id>.png` 打开原图复核。
- 自动指标（`analysis/metrics.csv`）只作为辅助交叉检查：调色直方图距离下降说明画面向参考图靠拢，
  但**参考内容被照搬时该距离同样会下降**，所以不能当成样式迁移成功的证据（见报告 §7）。
- 未评分格在 `scores.csv` 里写 `generated_unrated`，不会被计成通过或失败。
