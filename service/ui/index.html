文生图 图像编辑
选哪个？ ? 两个 Tab 的区别（依据官方 README + 本机实测） 文生图：只吃文字，从零画一张。参数里没有参考图，上传的图不会进模型。
图像编辑：文字 + 参考图（image 参数，最多 10 张）。官方 README 把 "多参考图" 归在 Image Editing → Multiple Reference Images， 用途写的是 multi-subject composition（多主体合成），示例是"六张单人头像合成一张合影"。
底层是同一个管线（QwenImage21Pipeline）： 传了 image 就是条件生成，没传就是纯文本生成。所以"编辑"并不是只能改一张图。
想让两个人物拥抱 → 用「图像编辑」并同时上传两张图，prompt 描述场景。
  • 只给一张参考图 → 模型只认识一个人，另一个得靠文字编，长相不受控
  • 给两张 → 两个人的身份都能被"看见"，这是官方支持的多主体合成
  • 输出比例默认跟随最后一张参考图（实测 A+B 出 1024²，B+A 出 896×1184）； 想固定就手填宽高或选档位
官方文档：Multi-Reference Editing，up to 10 reference images， "preserve identity for people and products"
